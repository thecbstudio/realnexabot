📱 WhatsApp Entegrasyon Kılavuzu

Müşterinin botu WhatsApp üzerinden de cevap versin. 5 adımda kurulum, Meta sandbox ile dakikalar içinde test edilebilir.

Onay süreci: Sandbox (test) modunda hemen kullanabilirsin — sadece test numaraları ekleyip mesaj atabilirsin. Gerçek müşterilerle (production) konuşabilmek için Meta'nın işletme doğrulama onayı 1-2 hafta sürer.
1

Meta Developer hesabı + uygulama oluştur

developers.facebook.com aç → giriş yap.

  • "My Apps" → "Create App"
  • Use case: Other
  • App type: Business
  • App name: NexaBot WhatsApp
2

WhatsApp ürününü ekle

Uygulama dashboard'ında sol menüden Add product → WhatsApp → Set up.

  • İşletme hesabı seç veya oluştur
  • Karşına API Setup sayfası gelir — burada 3 önemli bilgi var:
    • Phone number ID (test numarası, kopyala)
    • Temporary access token (24 saatlik — kopyala)
    • App secret (App Settings → Basic → Show)
İlk başta Meta'nın verdiği test numarası ile çalış. Sonra kendi numaranı ekleyebilirsin.
3

NexaBot admin'inde işletmeyi WhatsApp'a bağla

Admin paneline (/admin) git → ilgili işletmeyi aç → "WhatsApp" alanlarına şunları gir:

  • whatsapp_phone_number_id: Meta'dan kopyaladığın Phone Number ID
  • whatsapp_access_token: Temporary access token (sonra permanent token üretip değiştir)
  • whatsapp_app_secret: App settings → Basic → App secret
  • whatsapp_verify_token: Sen oluşturursun (rastgele uzun string, örn: nexa_wa_2026_x9k2m)

Kaydet.

4

Webhook'u Meta'ya bağla

Meta dashboard'da WhatsApp → Configuration → Webhook → Edit:

  • Callback URL (kendi NexaBot domain'in):
    https://nexabot-mkbjs.ondigitalocean.app/api/webhook/whatsapp/<BUSINESS_ID>
    BUSINESS_ID'yi admin panelden işletmenin ID'si ile değiştir.
  • Verify token: 3. adımda girdiğin verify_token ile AYNI olmalı
  • Subscribe to: messages

"Verify and save" — yeşil tik gelmeli.

5

Test et

Meta dashboard'da WhatsApp → API Setup → To alanına kendi WhatsApp numaranı ekle (alıcı listesine).

  • "Send message" butonu ile test mesajı gönder — telefonuna mesaj gelir
  • Telefonundan o numaraya CEVAP yaz → NexaBot bot devreye girer → cevap verir
  • Cevap gelmezse: DigitalOcean logs'a bak (NexaBot console → Runtime Logs)
Çalışıyor mu? Süper! Production için Meta business verification başlat (Settings → Basic → Submit for review). 1-2 hafta sürer.
Güvenlik notu: WhatsApp access token sızdırma — Meta'da System User oluşturup permanent token üret, geçici token yerine onu kullan. Token rotation 60 günde bir önerilir.
